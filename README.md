# Tasty Bites — Premium UI V3

Next.js customer menu prototype with category search, individual meal detail screens, configurable extras, special instructions, quantity selector, persistent cart, and delivery/pickup checkout preview.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Important

- All food illustrations are placeholders, not photographs of the restaurant's meals.
- Extra prices are illustrative and must be confirmed with Tasty Bites.
- Checkout is a demonstration only: no live orders, payments, database, or delivery fee calculation.
- Cart data is stored locally in the browser. No server submission is made.
